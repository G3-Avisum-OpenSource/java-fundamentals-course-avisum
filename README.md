# java-fundamentals-course-avisum

Repositorio público del curso **Fundamentos de Java para Principiantes**, diseñado para estudiantes de secundaria sin experiencia previa en programación.

## Contenido del Repositorio

- `/starter-files`: Archivos base iniciales con código plantilla para cada lección.
- `/completed-examples`: Soluciones completas de los ejemplos explicados en los videos.
- `/scripts` 
- `course-plan.md`: Plan integral del curso con enlaces a los videos de YouTube y entornos de práctica.

## Herramientas Gratuitas Online
No se requiere instalar Java ni ningún IDE local. Todo el código puede ser ejecutado directamente en el navegador web a través de:
- [Replit](https://replit.com)
- [JDoodle](https://www.jdoodle.com)
- [OnlineGDB](https://www.onlinegdb.com)
